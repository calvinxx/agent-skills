# agent-skills

Personal [Agent Skills](https://agentskills.io) for AI coding agents (pi, Claude Code, Codex, Cursor, ...).

## Skills

| Skill | What it does |
|---|---|
| [mise](mise/) | Manage runtimes with mise; default CLIs to mise, allowing npm global installs when required for self-updates |

## Install

With the [skills CLI](https://skills.sh):

```bash
npx skills add calvinxx/agent-skills
```

Or clone and symlink the skill directory into your agent's skills dir
(`~/.claude/skills/`, `~/.codex/skills/`, `~/.pi/agent/skills/`, `~/.agents/skills/`, ...).
